> 아트 방향·브랜드 승인: `PM` 대기

## 1. 원칙

- 에셋은 장식보다 의사결정 상태와 결과를 읽게 하는 데 우선 사용한다.
- 색만으로 상태를 전달하지 않고 형태, 아이콘, 텍스트를 함께 쓴다.
- 공식 기업 로고·상표 에셋은 PM 승인 전 사용하지 않는다.
- 원본은 SVG 또는 레이어가 분리된 소스여야 하며, 래스터가 필요하면 1x/2x를 함께 만든다.
- 파일명은 `kebab-case`, 상태 변형은 `asset-name--state.svg` 형식을 쓴다.
- 모든 에셋은 출처, 라이선스, 제작 주체, 모델 사용 여부를 manifest에 기록한다.

## 5. 에셋 manifest 형식

```json
{
  "id": "A-FAB-004",
  "files": ["fab-ramp-valley--enter.svg"],
  "purpose": "Ramp Valley 진입 경고",
  "screen": "game/fab",
  "states": ["enter", "active", "recover"],
  "creator": "Codex",
  "generator_model": null,
  "source": "original",
  "license": "project-owned",
  "reviewer": "PM",
  "status": "draft"
}
```

에셋 제작 도구나 생성 모델을 사용했다면 `generator_model`과 생성·편집 주체를 반드시 채운다.
